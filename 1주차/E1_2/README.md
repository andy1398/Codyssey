# 6. 데이터 파일 설명(state.json 등)
병렬 배열(Parallel Arrays) 구조이다.
여러 개의 연관된 데이터를 각 데이터 종류별로 독립된 배열(리스트)에 나누어 담되, '같은 인덱스(순서)'를 매개로 하나의 묶음처럼 사용했다.
json 파일은 파일을 읽을때 모든 내용을 읽고 수정은 읽은 후에 가능하다. 즉 내용이 많을수록 w/r 속도가 느리다. 
반면 디비는 인덱스(Index)와 SQL 쿼리를 사용해 전체 데이터 중 원하는 1개의 행(Row)만 직접 찾아서 읽고 수정합니다. 데이터가 100만 개로 늘어나도 수정 속도는 거의 일정하게 유지됩니다. 
json은 동시에 w/r을 하면 파일 손상/락이 걸린다. 반면 디비는 트랜잭션(Transaction) 기능을 제공하여, 여러 요청이 동시에 들어와도 데이터가 충돌하지 않고 안전하게 처리됩니다. 또한 중간에 전원이 꺼져도 데이터 복구가 가능하다.
